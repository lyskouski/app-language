# Tlum: Aplikasi Belajar Bahasa

**Tlum** adalah aplikasi belajar bahasa sumber terbuka dan lintas platform. Aplikasi ini
memanfaatkan pemrosesan bahasa alami untuk menemukan kelemahan pelafalan Anda secara tepat, serta
pembelajaran mesin untuk meningkatkan penguasaan kosakata Anda.

## Fungsionalitas

- Buat pasangan bahasa Anda sendiri
- Kelompokkan setiap pasangan bahasa ke dalam kategori
- Tambahkan kata baru ke kategori
- Impor dan ekspor pasangan bahasa beserta semua kategori dan katanya
- Antarmuka mode terang dan mode gelap
- Antarmuka dalam 26 bahasa: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ,
  JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Latihan

- **Kartu**: kata di bagian depan kartu dan terjemahannya di bagian belakang
- **Harmonika**: latihan menulis: tulis teks asli atau terjemahannya
- **Harmonika Akustik**: latihan menulis berdasarkan apa yang Anda dengar
- **Artikulasi**: alat untuk melatih pelafalan
