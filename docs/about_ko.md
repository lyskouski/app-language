# Tlum: 언어 학습 애플리케이션

**Tlum**은 오픈 소스 크로스 플랫폼 언어 학습 애플리케이션입니다. 자연어 처리로 발음의 약점을 정확히
찾아내고, 머신 러닝으로 어휘 실력을 높여 줍니다.

## 기능

- 나만의 언어 쌍 만들기
- 각 언어 쌍을 카테고리별로 정리하기
- 카테고리에 새 단어 추가하기
- 모든 카테고리와 단어를 포함한 언어 쌍 가져오기 및 내보내기
- 라이트 모드와 다크 모드 인터페이스
- 26개 언어 인터페이스: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ,
  JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## 연습

- **카드**: 카드 앞면에는 단어, 뒷면에는 그 번역
- **하모니카**: 쓰기 연습: 원문 또는 그 번역을 작성하기
- **어쿠스틱 하모니카**: 들은 내용을 바탕으로 하는 쓰기 연습
- **조음 연습**: 발음 훈련 도구
