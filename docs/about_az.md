# Tlum: Dil Öyrənmə Tətbiqi

**Tlum** açıq mənbəli, çoxplatformalı dil öyrənmə tətbiqidir. O, tələffüzünüzdəki boşluqları dəqiq
müəyyən etmək üçün təbii dil emalından, lüğət biliyinizi artırmaq üçün isə maşın öyrənməsindən
istifadə edir.

## Funksionallıq

- Öz dil cütlərinizi yaradın
- Hər dil cütünü kateqoriyalara ayırın
- Kateqoriyalara yeni sözlər əlavə edin
- Dil cütünü bütün kateqoriyaları və sözləri ilə birlikdə idxal və ixrac edin
- İşıqlı və qaranlıq interfeys rejimi
- 26 dildə interfeys: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA,
  ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Təcrübələr

- **Kartlar**: kartın ön üzündə söz, arxa üzündə isə onun tərcüməsi
- **Dodaq qarmonu**: yazı məşqi: ya orijinal mətni, ya da onun tərcüməsini yazın
- **Akustik dodaq qarmonu**: eşitdiklərinizə əsaslanan yazı məşqi
- **Artikulyasiya**: tələffüz üzrə məşq aləti
