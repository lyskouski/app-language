# Tlum: приложение для изучения языков

**Tlum** — это кроссплатформенное приложение для изучения языков с открытым исходным кодом. Оно
использует обработку естественного языка, чтобы выявить пробелы в вашем произношении, и машинное
обучение, чтобы расширить ваш словарный запас.

## Функциональность

- Создавайте собственные языковые пары
- Распределяйте каждую языковую пару по категориям
- Добавляйте новые слова в категории
- Импорт и экспорт языковой пары со всеми её категориями и словами
- Светлая и темная тема интерфейса
- Интерфейс на 26 языках: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ,
  JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Практики

- **Карты**: слово на лицевой стороне карточки и его перевод на обороте
- **Гармошка**: письменное упражнение — напишите оригинальный текст или его перевод
- **Акустическая гармошка**: письменное упражнение на основе услышанного
- **Артикуляция**: тренажер произношения
