# Tlum — Learn Words. Practice. Speak.

Finish on the Tlum logo. | “Meet Tlum, a free, open-source language learning app for Android, iOS, Windows and Linux. Build your own vocabulary and practise reading, writing and pronunciation—all in one place.” |

| 0:35–1:05 | **Choose the languages you want to learn** | Tap the central Add Language Pair button. Enter a name, select the source and target languages, optionally add a logo, and save. | 3:35–4:05 | **Game 3: Acoustic Harmonica** | Open Acoustic Harmonica. Play an audio prompt, type what you hear, and show one answer with feedback. | 5:00–5:35 | **Take your dictionary with you** | Return to the pair list. Export a pair, then import a prepared dictionary using Merge (append words, keep existing).
