# Tlum：語学学習アプリ

**Tlum**は、オープンソースのクロスプラットフォーム語学学習アプリです。自然言語処理で発音の弱点を的確に見つけ出し、機械学習で語彙力の向上をサポートします。

## 機能

- 自分だけの言語ペアを作成
- 各言語ペアをカテゴリーごとに整理
- カテゴリーに新しい単語を追加
- 言語ペアをすべてのカテゴリーと単語ごとインポート・エクスポート
- ライトモードとダークモードのインターフェース
- 26言語に対応したインターフェース：EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## 練習

- **カード**：カードの表に単語、裏にその翻訳
- **ハーモニカ**：書き取り練習：原文またはその翻訳を書きます
- **音響ハーモニカ**：聞き取った内容をもとにした書き取り練習
- **発音練習**：発音トレーニングツール
