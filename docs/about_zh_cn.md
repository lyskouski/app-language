# Tlum：语言学习应用

**Tlum** 是一款开源、跨平台的语言学习应用。它借助自然语言处理精准找出您发音中的薄弱环节，并通过机器学习帮助您提升词汇掌握水平。

## 功能

- 创建您自己的语言对
- 将每个语言对整理为不同类别
- 向类别中添加新单词
- 导入和导出语言对及其所有类别和单词
- 浅色模式和深色模式界面
- 界面支持 26 种语言：EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## 练习

- **卡片**：卡片正面是单词，背面是它的翻译
- **口琴**：书写练习：写出原文或其译文
- **原声口琴**：根据所听内容进行的书写练习
- **发音练习**：一款发音训练工具
