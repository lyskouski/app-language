# Tlum: застосунок для вивчення мов

**Tlum** — це кросплатформний застосунок для вивчення мов із відкритим вихідним кодом. Він
використовує обробку природної мови, щоб виявити прогалини у вашій вимові, і машинне навчання, щоб
розширити ваш словниковий запас.

## Функціональність

- Створюйте власні мовні пари
- Розподіляйте кожну мовну пару за категоріями
- Додавайте нові слова до категорій
- Імпорт та експорт мовної пари з усіма її категоріями та словами
- Світла й темна тема інтерфейсу
- Інтерфейс 26 мовами: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA,
  ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Практики

- **Картки**: слово на лицьовому боці картки та його переклад на звороті
- **Гармошка**: письмова вправа — напишіть оригінальний текст або його переклад
- **Акустична гармошка**: письмова вправа на основі почутого
- **Артикуляція**: тренажер вимови
