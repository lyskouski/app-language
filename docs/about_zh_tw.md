# Tlum：語言學習應用程式

**Tlum** 是一款開源、跨平台的語言學習應用程式。它運用自然語言處理精準找出您發音上的不足之處，並透過機器學習幫助您提升詞彙能力。

## 功能

- 建立您自己的語言組合
- 將每個語言組合整理成不同類別
- 在類別中新增單字
- 匯入和匯出語言組合及其所有類別與單字
- 淺色模式與深色模式介面
- 介面支援 26 種語言：EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## 練習

- **卡片**：卡片正面是單字，背面是它的翻譯
- **口琴**：書寫練習：寫出原文或其譯文
- **原聲口琴**：根據聽到的內容進行的書寫練習
- **發音練習**：一款發音訓練工具
