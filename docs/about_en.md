# Tlum: Language Learning Application

**Tlum** is an open-source, cross-platform language learning application. It uses natural language
processing to pinpoint gaps in your pronunciation and machine learning to boost your vocabulary
proficiency.

## Functionality

- Create your own language pairs
- Organise each language pair into categories
- Add new words to categories
- Import and export a language pair with all its categories and words
- Light and dark interface mode
- Interface in 26 languages: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ,
  JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Practices

- **Cards**: a word on the front of the card and its translation on the back
- **Harmonica**: a writing exercise: write either the original text or its translation
- **Acoustic Harmonica**: a writing exercise based on what you hear
- **Articulation**: a pronunciation training tool
