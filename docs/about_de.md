# Tlum: App zum Sprachenlernen

**Tlum** ist eine quelloffene, plattformübergreifende App zum Sprachenlernen. Mithilfe von Natural
Language Processing erkennt sie gezielt Schwächen in Ihrer Aussprache, und maschinelles Lernen hilft
Ihnen, Ihren Wortschatz sicher auszubauen.

## Funktionen

- Eigene Sprachpaare anlegen
- Jedes Sprachpaar in Kategorien gliedern
- Neue Wörter zu Kategorien hinzufügen
- Ein Sprachpaar mit allen Kategorien und Wörtern importieren und exportieren
- Hellmodus und Dunkelmodus für die Oberfläche
- Oberfläche in 26 Sprachen: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ,
  JA, ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## Übungen

- **Karten**: vorne auf der Karte steht ein Wort, auf der Rückseite seine Übersetzung
- **Harmonika**: eine Schreibübung – schreiben Sie entweder den Originaltext oder seine Übersetzung
- **Akustische Harmonika**: eine Schreibübung nach Gehör
- **Artikulation**: ein Werkzeug zum Trainieren der Aussprache
