If you mean your Tlum application in App Store Connect, the TestFlight link is not generated automatically just from uploading the app. You need to create a Public Link for an external testing group.
Get the TestFlight public link
1. Open App Store Connect.
2. Go to Apps → Tlum.
3. Open the TestFlight tab.
4. In the left sidebar, under External Testing, select an existing testing group.
   - If you don't have one, click + next to External Testing and create a group.
5. Add your uploaded Tlum build to that group.
6. In the Testers section, click Create Public Link.
7. Select Open to Anyone (or specify device/iOS criteria).
8. Click Confirm.
9. Copy the generated URL.
Apple's current instructions confirm this flow: TestFlight → External Testing → group → Testers → Create Public Link. Apple Developer
The resulting link will look approximately like:
https://testflight.apple.com/join/XXXXXXXX

You can give this link to users; they open it on an Apple device, accept the invitation, and install Tlum through TestFlight. TestFlight
If "Create Public Link" isn't available
Usually one of these is missing:
- no external testing group;
- no build added to the group;
- the build hasn't passed the required TestFlight App Review for external testing;
- your App Store Connect role doesn't have sufficient permissions.
For external testing, Apple allows up to 10,000 external testers per app. Apple Developer
