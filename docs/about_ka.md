# Tlum: ენების შესწავლის აპლიკაცია

**Tlum** არის ღია კოდის, მრავალპლატფორმული აპლიკაცია ენების შესწავლისთვის. ის ბუნებრივი ენის
დამუშავების მეშვეობით ზუსტად ავლენს თქვენი წარმოთქმის ხარვეზებს, ხოლო მანქანური სწავლების დახმარებით
აუმჯობესებს თქვენს ლექსიკურ მარაგს.

## ფუნქციონალი

- შექმენით საკუთარი ენათა წყვილები
- დაალაგეთ თითოეული ენათა წყვილი კატეგორიებად
- დაამატეთ ახალი სიტყვები კატეგორიებში
- მოახდინეთ ენათა წყვილის იმპორტი და ექსპორტი ყველა მისი კატეგორიითა და სიტყვით
- ინტერფეისის ღია და მუქი რეჟიმი
- ინტერფეისი 26 ენაზე: EN, BE, PL, PT-PT, PT-BR, FR, DE, UK, ZH-CN, ZH-TW, HI, UZ, FA, AR, AZ, JA,
  ES, IT, TR, KO, NL, CS, RO, KA, RU, ID

## პრაქტიკა

- **ბარათები**: სიტყვა ბარათის წინა მხარეს, მისი თარგმანი კი — უკანა მხარეს
- **ჰარმონიკა**: წერითი სავარჯიშო: დაწერეთ ორიგინალი ტექსტი ან მისი თარგმანი
- **აკუსტიკური ჰარმონიკა**: წერითი სავარჯიშო მოსმენილის საფუძველზე
- **არტიკულაცია**: წარმოთქმის სავარჯიშო ინსტრუმენტი
